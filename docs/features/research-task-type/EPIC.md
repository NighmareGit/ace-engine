## Problem

The engine only executes code atoms: pass/fail is compile+tests, N4
measures commits, and the S9 review proved that artifact-shaped output
without substance (hollow commits, mock-theater tests) sails through any
"did it produce a file" metric. Research work — the beellama tiered-memory
epic and every future exploration task — has no oracle at all: an LLM
either writes uncited prose or nothing verifiable.

## Solution

A `research` task type: the atom produces a **cited verdict document**
(`verdict.md` with `[claim-N]`/`[src-N]` markers) plus a **deterministic
sidecar** (`verdict.evidence.json`, generated by post-processing the
markers, never by the LLM). The gate is two-layer per ADR-0004:

1. **Deterministic floor** — staged `EvidenceValidator` mirroring
   `validator.py` (stages 0–5, short-circuit, report-all within stage):
   structure, citation format, claim coverage, source reachability,
   no self-support, **no cycles in either the claim→source graph or the
   source→source graph**, claim density ≥2/1000 tokens, contradictions
   carry resolutions, answer-the-question TF-IDF check (reuses
   `engine/intent/similarity.py`), mandatory verdict position
   (supported/refuted/inconclusive + confidence). No LLM sets `passed`.
2. **LLM entailment scoring** — `EvidenceScorer` (judge model, 5
   dimensions: citation_coverage, claim_traceability,
   contradiction_handling, verdict_justification, source_quality),
   threshold **6.0** (owner-set; S9 lesson: kind thresholds pass hollow
   work). Gate consumes scores; never the reverse.

Dispatch is a **`TaskHandler` strategy protocol** — one `task_type`
branch at the top of `_run_task()`; the existing body becomes
`CodeTaskHandler` with zero behavior change. New logic lives in the
`engine/research/` package (verdict, evidence, scoring, sources,
sidecar, facade); existing files get registration hooks only.

**file:// source verification is in v1** (owner decision): path must
exist (traversal rejected) and the evidence span must substring-match
the file content; sampled 20%, escalate to 100% on failure. HTTP
accessibility is v2.

## Schema (additive-only)

- `research_verdicts` — verdict-level summary + artifact paths
- `research_scores` — 5 judge dimensions, `overall` generated column
- claims/sources/edges live in the sidecar JSON (2 tables, not 4 —
  avoids DB/JSON sync)

## Dogfood mission spec: beellama tiered-memory research epic

Deliverable = **research + design only** (implementation is a later
epic). Preconditions: campaign `feature/three-tier-expert-cache` rebased
onto upstream tip (measured LOW-RISK: merge-tree clean, MoE path
untouched; see HW-MEASUREMENTS appendix 2). Research atoms R01–R08 in
`../../.scratch/research-task-type/DOGFOOD-SPEC-beellama.md`:

- **R01 branch selection** (v0.4.7 vs main vs pinned merge, 222-commit
  drift) · **R02 portability mechanism** (quilt series vs feature module
  vs fork — the core deliverable; cannot presuppose its conclusion;
  must include reapplication procedure + llama.cpp-port contingency) ·
  **R03 PR reconciliation** (#27861 × #25294, 7 shared files, adapter
  design against the CURRENT graph layout) · **R04 tier sizing** (using
  measured host numbers: 1.6 GB/s L800 / 673 MB/s NV2 NVMe, Gen4/Gen3
  PCIe, no GPU P2P; LRU vs ARC vs 3-band prefetch) · **R05 DFlash×SSD
  interaction** (break-even, route-ahead prefetch) · **R06 kvarn
  orthogonality on v0.4.7** · **R07 telemetry surface** · **R08
  pin-vs-track drift policy**.

Each atom: one verdict pair ≥6.0, file:// or fetched-to-disk sources,
contradictions flagged with resolutions (e.g. phasebuffer ARC vs
PR #27861 LRU).

## Non-goals

1. No code-atom behavior change (research path is purely additive).
2. No G13 gate-gaming divergence signal (deferred, ledgered).
3. No HTTP source accessibility in v1 (structural + file:// only).
4. No real-time source fetching; the oracle checks structure + local
   content, not remote truth.
5. No research-specific autopsy section in v1 (sections 1–3, 6 free;
   validation trace shows EvidenceResult.checks via same column).
6. No TGD research signals in v1 (`"unknown"` class acceptable).
7. No multi-round aggregation module (orchestrator-level in v1).

## Success metrics

- Bad-verdict corpus: **≥90% deterministic rejection**, valid case
  passes, zero false positives.
- Beellama dogfood: 8 verdicts ≥6.0 committed with sidecars; ≥0 hollow
  verdicts pass (S9-invariant).
- Full engine suite green at every wave.
